# Rushabh Shah - Portfolio Website

Modern, mobile-responsive, multi-page portfolio website for **Rushabh Shah** built using **Next.js 14+ (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Python (FastAPI)**.

## 🚀 Live Preview Links
- **GitHub Repository**: [https://github.com/Rushabh16-9/portfolio](https://github.com/Rushabh16-9/portfolio)
- **Local Frontend**: [http://localhost:3000](http://localhost:3000)
- **Local FastAPI API**: [http://localhost:8000/docs](http://localhost:8000/docs)

## 🌟 Tech Stack
- **Frontend**: Next.js 14.2.23 (App Router), React 18, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: Python 3.10+ (FastAPI), Pydantic, SQLite, Uvicorn
- **AI Integration**: Custom Portfolio Assistant ("Rushabh AI") for interactive visitor queries
